# hypridle

hypridle: run commands when the seat goes idle and comes back, and the loginctl that reaches it. An app (Ferrix's [docs/APPS.md](https://github.com/ferrix-os/ferrix/blob/main/docs/APPS.md)): `app.toml` says what it installs and how it is built; its licence is `MIT`. Every desktop carries it whether or not the app is installed.
