# alsa-lib

alsa-lib's configuration, for the programs linked against ALSA's library. An app (Ferrix's [docs/APPS.md](https://github.com/ferrix-os/ferrix/blob/main/docs/APPS.md)): `app.toml` says what it installs and how it is built; its licence is `LGPL-2.1-or-later`.
