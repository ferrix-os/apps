# git

git, static against ferrousli, with HTTP(S) through libcurl. An app (Ferrix's [docs/APPS.md](https://github.com/ferrix-os/ferrix/blob/main/docs/APPS.md)): `app.toml` says what it installs and how it is built; its licence is `GPL-2.0-only AND curl AND Zlib AND (Apache-2.0 OR GPL-2.0-or-later)`.
