# term

term: Ferrix's terminal emulator, a pseudoterminal, a character grid and a Wayland window. An app (Ferrix's [docs/APPS.md](https://github.com/ferrix-os/ferrix/blob/main/docs/APPS.md)): `app.toml` says what it installs and how it is built; its licence is `MIT AND Bitstream-Vera`. Every desktop carries it whether or not the app is installed.
