# sshdt

sshdt, an SSH server in Rust, static against ferrousli. An app (Ferrix's [docs/APPS.md](https://github.com/ferrix-os/ferrix/blob/main/docs/APPS.md)): `app.toml` says what it installs and how it is built; its licence is `MIT OR Apache-2.0`.
