# foot

foot, the Wayland terminal, static against ferrousli, with DejaVu. An app (Ferrix's [docs/APPS.md](https://github.com/ferrix-os/ferrix/blob/main/docs/APPS.md)): `app.toml` says what it installs and how it is built; its licence is `MIT AND (FTL OR GPL-2.0-or-later) AND HPND-sell-variant AND Bitstream-Vera`.
