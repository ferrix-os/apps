# waybar

waybar in Rust: the user's config.jsonc and GTK3 style.css, drawn as a layer-shell bar. An app (Ferrix's [docs/APPS.md](https://github.com/ferrix-os/ferrix/blob/main/docs/APPS.md)): `app.toml` says what it installs and how it is built; its licence is `MIT`. Every desktop carries it whether or not the app is installed.
