# alsa-utils

aplay, arecord and speaker-test, static against ferrousli. An app (Ferrix's [docs/APPS.md](https://github.com/ferrix-os/ferrix/blob/main/docs/APPS.md)): `app.toml` says what it installs and how it is built; its licence is `GPL-2.0-or-later AND LGPL-2.1-or-later`.
